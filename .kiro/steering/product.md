# Product Overview

## Dixie Chemical Product Agent v3

An agentic RAG (Retrieval-Augmented Generation) application that provides intelligent search and question-answering capabilities over technical chemical product documents. The system combines vector database search with knowledge graph reasoning to deliver precise, contextual answers about chemical products, their properties, applications, and relationships.

## Core Capabilities

- **Hybrid Retrieval**: Combines vector similarity search with knowledge graph traversal
- **Technical Document Processing**: Extracts and validates data from chemical product technical bulletins
- **Conversational Interface**: Natural language chat interface for product inquiries
- **Product Browser**: Searchable catalog with detailed product information and comparisons
- **Automated Workflows**: n8n-based automation for data ingestion and quality monitoring

## Target Users

- Chemical engineers and researchers
- Product application specialists
- Sales and technical support teams
- Quality assurance professionals

## Key Differentiators

- Domain-specific knowledge graph for chemical products
- Validated extraction pipeline ensuring data accuracy
- Multi-modal search combining semantic and structured queries
- Real-time source attribution and provenance tracking
